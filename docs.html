WhatsApp API (Baileys) — Dokumentasi

File: server.js — API ringan berbasis WebSocket (tanpa Chromium/Puppeteer).

Server

Base URL: http://localhost:5000 (atau env PORT).

Di production diakses lewat nginx: https://www.zeatextile.cloud/wa-api.

Daftar Endpoint

MethodPathDeskripsi
GET/healthHealth check. { "status": "ok", "ready": bool, "uptime": number }.
GET/statusStatus koneksi. { "ready": bool, "info": { "wid", "pushName", "platform" } | null }.
GET/qrAmbil QR (data URL PNG). Kalau sudah terhubung: { "status": true, "qr": null, "message": "Already connected" }.
POST/sendKirim teks. Body: { "number": "62812...", "message": "..." }.
POST/send-fileKirim file. Multipart (file, number, caption), atau JSON fileBase64/fileUrl. Mendukung PDF, gambar, video, dokumen.
POST/logoutLogout dari WhatsApp (hapus sesi aktif).
POST/client/restartLogout lalu inisialisasi ulang socket.

Contoh penggunaan

1) Cek status

curl http://localhost:5000/status

2) Ambil QR

curl http://localhost:5000/qr
# Buka data URL "qr" di browser untuk scan dengan WhatsApp

3) Kirim pesan

curl -X POST http://localhost:5000/send \
  -H "Content-Type: application/json" \
  -d '{"number":"628123456789","message":"Halo dari API"}'

PowerShell:

$body = @{ number = '628123456789'; message = 'Halo dari API' } | ConvertTo-Json
Invoke-RestMethod -Uri http://localhost:5000/send -Method Post -Body $body -ContentType 'application/json'

4) Kirim PDF (multipart)

curl -X POST http://localhost:5000/send-file \
  -F "file=@/path/to/doc.pdf" \
  -F "number=089530518554" \
  -F "caption=Dokumen PDF"

5) Kirim file via URL (JSON)

curl -X POST http://localhost:5000/send-file \
  -H "Content-Type: application/json" \
  -d '{"number":"628123456789","fileUrl":"https://example.com/doc.pdf","caption":"Dokumen"}'

Alur autentikasi & session

  1. Auth state disimpan otomatis di folder auth/ (Docker: volume whatsapp_auth di /app/auth).
  2. Belum terautentikasi → buka /qr, scan dengan WhatsApp di ponsel.
  3. Setelah scan, koneksi open dan sesi otomatis tersimpan — restart container tidak perlu scan ulang.
  4. Gunakan /logout untuk memutus & menghapus sesi.
Jaga folder auth/ tetap aman. Siapa pun yang memilikinya bisa mengakses akun WhatsApp yang terhubung.
